Place Poppins font files here (not included). Filename and weights must match the `pubspec.yaml` fonts section:

- Poppins-Regular.ttf
- Poppins-Medium.ttf (weight 500)
- Poppins-SemiBold.ttf (weight 600)
- Poppins-Bold.ttf (weight 700)

You can download these from Google Fonts and copy them into this folder. After adding the files, run:

```bash
cd D:/projects/Loopo/loopo
flutter pub get
flutter clean
flutter run
```
